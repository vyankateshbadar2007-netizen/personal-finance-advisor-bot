Project specification

Requirements covered inside the MVP

The interface below mirrors the supplied project brief: scenarios, skills, stats, architecture, system requirements, prerequisites, workflow, UI requirements, deployment flow and conclusion.

01

Salaried professional

Logs monthly income and category expenses such as rent, food, transport and entertainment; the system finds overspending, creates a personalized budget and produces a month-end summary with income, expenses, savings and next-month goals.

02

College student

Manages a limited monthly allowance, sets realistic category limits, tracks spending habits and receives suggestions to reduce discretionary expenditure and improve savings discipline.

03

Freelancer

Tracks multiple client earnings and project expenses, adapts budget recommendations to fluctuating income, identifies lower-saving months and suggests emergency-fund strategies.

04

Household manager

Monitors shared family income and expenses such as groceries, utilities, education and healthcare; the bot identifies overruns and supports resource allocation and family savings goals.

Project conclusion

The Personal Finance Advisor Bot is designed as an AI-powered financial planning assistant that helps users log income and expenses, generate budget plans, understand spending patterns, receive saving recommendations and monitor monthly performance. The architecture described in the project brief is scalable toward Flask, SQLAlchemy/SQLite, Gemini AI and Google Sheets, while this standalone MVP demonstrates the complete front-end experience and core finance logic without requiring a backend server to run.

API security: never commit or publish a Gemini API key. In the full Flask architecture, keep the key in .env and load it server-side. The optional browser key in this MVP exists only for live demonstration and is not embedded in the file.
